# Install socat for local Unix-socket control

**Date:** 2026-09-07

## Motivation

Install `socat` on Bredland to provide a simple command-line client for local Unix domain sockets.

The immediate use case is the rapid-poll instrumentation service used during trusted RouterOS action rehearsals and timing measurements.

The instrumentation service exposes a local control socket at:

```text
/tmp/rapid-poll-instrumentation.sock
```

Using `socat` allows operator commands to remain simple and explicit, for example:

```bash
printf 'status\n' | socat - UNIX-CONNECT:/tmp/rapid-poll-instrumentation.sock
```

This avoids requiring ad-hoc Python socket clients for routine manual operation.

## Procedure

Install `socat` using the Debian package manager:

```bash
sudo apt update
sudo apt install socat
```

No additional configuration is required.

## Verification

Verify that `socat` is installed:

```bash
command -v socat
```

Expected result:

```text
/usr/bin/socat
```

When the rapid-poll instrumentation service is running, verify communication with its control socket:

```bash
printf 'status\n' | socat - UNIX-CONNECT:/tmp/rapid-poll-instrumentation.sock
```

Expected result when the instrument is idle:

```text
inert
```

## Rollback

Remove the package:

```bash
sudo apt remove socat
```

## Notes

`socat` is a general-purpose host utility rather than a runtime dependency of the trusted discovery service.

The trusted discovery service communicates with the rapid-poll instrumentation socket directly in Python and does not depend on the `socat` executable.

`socat` is installed for operator convenience when manually controlling or inspecting local Unix-socket services.
