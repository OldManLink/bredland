# 🍕 BRD-021 — Add MikroTik latest firmware version telemetry

## Status

Planned

## Goal

Expose the latest available RouterOS version as part of the MikroTik heartbeat.

The MikroTik client already reports whether a software update is available through the `update_available` boolean field. This slice adds the missing context needed for the NOC to explain what update is available.

---

## Design

The MikroTik heartbeat shall include a new string field:

```json
"latest_version": "7.23.2"
```

The value shall be obtained from the existing RouterOS package update information.

The field shall only represent the latest available version reported by RouterOS. It shall not trigger updates or change the update workflow.

---

## Acceptance Criteria

- MikroTik heartbeats include a `latest_version` field. ✅
- The value matches the latest RouterOS version reported by the router. ✅
- The field is included in the MikroTik client description. ✅
- Existing MikroTik telemetry fields continue to function unchanged. ✅

---

## Notes

This slice deliberately only exposes the missing telemetry.

Displaying notifications based on `update_available` and `latest_version` is handled separately using the declarative dashboard rules introduced by BRD-016.
